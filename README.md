# Typing Test Website - MANSU

## 🎯 Features

A clean, simple, and fast typing test website that helps you improve your typing speed and accuracy.

### Core Features:
- **⏱️ Flexible Test Duration**: Choose between 10, 20, or 30-minute typing tests
- **⌨️ Live Statistics**: Real-time WPM (Words Per Minute), accuracy, and mistake tracking
- **📊 Spelling Check**: Built-in English dictionary for automatic spelling verification
- **✏️ Detailed Results**: Complete test results including:
  - Words Per Minute (WPM)
  - Accuracy Percentage
  - Total Test Time
  - Total Corrections Made
  - Spelling Mistakes Detected
  - Backspace Usage Count
- **⏸️ Pause/Resume**: Pause your test anytime and resume when ready
- **🏁 Finish Button**: End your test early if needed
- **🎨 Modern UI**: Clean, gradient-based design for a great user experience
- **📱 Responsive**: Works perfectly on desktop and mobile devices

## 🚀 How to Use

1. Open `index.html` in your web browser
2. Click on your preferred test duration (10, 20, or 30 minutes)
3. Paste your own text from your book or any source into the typing area
4. Start typing and watch your real-time statistics update
5. Use the **Pause** button to pause the test anytime
6. Click **Finish Test** to end the test early
7. View your comprehensive results when the test completes

## 📈 Understanding Your Results

- **WPM**: Words typed correctly per minute
- **Accuracy**: Percentage of correctly typed characters
- **Corrections**: Number of times you used backspace/correction
- **Mistakes**: Number of misspelled words detected
- **Backspace Usage**: Total number of times backspace was pressed

## 🔤 Spelling Dictionary

The website includes a free English dictionary with over 200 common English words. Words are checked against this dictionary, and any misspelled words are highlighted in the results.

## ✨ Features Explained

### WPM Calculation
- Calculated as: Total Words Typed ÷ Time in Minutes
- Updates in real-time as you type

### Accuracy Calculation
- Based on corrections and spelling mistakes
- Formula: 100 - (Errors / Total Characters) × 100
- Shown as a percentage

### Spelling Check
- Uses a built-in English dictionary
- Detects misspelled words in real-time
- Shows detailed spelling error report after test

### Backspace Tracking
- Counts every time you press backspace
- Helps you understand correction patterns
- Useful for analyzing typing habits
